# Contributing

Thanks for looking. bier is a small project with a strong opinion about
its design — please read the reasons before changing one.

- **[System overview](docs/contributing/system-overview.md)** — bier,
  bier-agent and Bierkasten, technically
- **[Architecture](docs/contributing/architecture.md)** — layout and how
  the parts fit together
- **[Design decisions](docs/contributing/design-decisions.md)** — and the
  traps that have already sprung
- **[Tests](docs/contributing/testing.md)** — `test/run`, green before
  every push
- **[Versions and releases](docs/contributing/releasing.md)**

Pull requests are read before they are merged. Code, comments, output and
documentation are in English.

Security problems: see [SECURITY.md](SECURITY.md), not the issue tracker.
