# bier search

```
bier search <name>
```

What Homebrew (casks and formulae) and the App Store have by that name,
one line each — `FOUND <kind> <name> <on a list: yes|no>` — for
Bierkasten's *Add Software* and for finding the name to give
[`bier place`](place.md).
