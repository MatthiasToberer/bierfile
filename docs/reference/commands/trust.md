# bier trust

```
bier trust
bier trust <url>
bier trust --forget
```

Pins the key that bier releases must be signed with. Without arguments,
shows the pinned keys and where they came from. `bier peer trust` is an
alias.

**See also:** [Signed releases](../../security/signed-releases.md)
