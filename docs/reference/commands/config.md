# bier config

```
bier config
bier config inventory automatic|manual
```

Shows the settings in effect — config file and environment combined —
and the Macs found in `Brewfiles/`.

`inventory manual` stops `bier sync` from recording installed software;
the Brewfiles stay exactly as you write them. `automatic` is the
default.
